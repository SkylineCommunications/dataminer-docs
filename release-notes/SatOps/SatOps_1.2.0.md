# SatOps 1.2.0

> [!NOTE]
> This version requires:
>
> - DataMiner 10.5.11/10.6.0 or higher, as well as DataMiner Web 10.6.2 or higher.
> - [MediaOps Plan 1.6.0](xref:MediaOps_Plan_1.6.0) or higher.

## Enhancements

#### SatOps now registered in Standard Data Model Registration [ID 46440]

SatOps now registers the installed solution and its version in Standard Data Model Registration. This makes the installed SatOps Solution available in the registration overview for DataMiner Solutions and models.

#### SatOps now compatible with MediaOps Plan 1.6.0 [ID 46441]

SatOps is now compatible with MediaOps Plan 1.6.0, allowing it to continue working in environments that use this MediaOps Plan version.
