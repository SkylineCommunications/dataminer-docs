# MbgNMS 1.4.2

## Enhancements

### Discovery support for LANTIME API version 20 or higher [ID 46074]

It is now possible to discover a new LANTIME device running API version 20 or higher.

### Support for microSync API version 3 [ID 46075]

Support is now available for microSync devices using API version 3.
