# Managing satellites

A *satellite* is the top-level entry in the Satellite Inventory. You create and manage satellites through guided, interactive dialogs in the Satellite Inventory app. Each satellite groups one or more [beams](xref:SI_Managing_Beams).

Using the app, you can:

- Create a new satellite and edit its properties.
- Import satellite demo data from a predefined template to quickly populate your environment.
- Visualize the satellite and its underlying beams and transponders in an interactive node edge graph.
