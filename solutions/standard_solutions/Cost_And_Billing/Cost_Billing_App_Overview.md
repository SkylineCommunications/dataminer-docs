# Cost & Billing app overview

All configuration and day-to-day operations for the Cost & Billing Solution are done via the Cost & Billing app. This ranges from the initial configuration of value units, over the creation of rate cards and contracts, to the synchronization of data from the external system and the calculation of the cost and billing of billable events.

![Cost & Billing app with the side panel expanded so all page names are visible](~/solutions/images/CostAndBilling_Contracts_expanded.png)

The following pages are available in the app:

- ![Contracts icon](~/solutions/images/Contracts_icon.png) **Contracts**:  Allows you to view and [configure contracts](xref:Cost_Billing_Configuring_Contracts).
- ![Rate cards icon](~/solutions/images/Rate_cards_icon.png) **Rate Cards**: Allows you to view and [configure rate cards](xref:Cost_Billing_Configuring_Rate_Cards).
- ![Items and groups icon](~/solutions/images/Items_and_groups_icon.png) **Items and Groups**: Allows you to [manage items and groups](xref:Cost_Billing_Managing_Items_Groups) that have been brought into the solution via the [external solution integration](xref:Cost_Billing_Integration).
- ![Events icon](~/solutions/images/CB_Events_icon.png) **Events**: Allows you to [manage billable events](xref:Cost_Billing_Managing_Billable_Events).
- ![Value units icon](~/solutions/images/CB_value_units_icon.png) **Value Units**: Allows you to [configure value units](xref:Cost_Billing_Configuring_Value_Units). This is usually the first thing to do after the solution has been deployed.
- ![Logs icon](~/solutions/images/CB_Logs_icon.png) **Logs**: Allows you to view any errors that have occurred during the [cost & billing calculation](xref:Cost_Billing_Managing_Billable_Events#calculating-the-cost-and-billing-for-billable-events).
