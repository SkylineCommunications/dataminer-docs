# Managing SLA templates

The *Templates* page gives you a card overview of all reusable SLA configuration templates, such as the tracking window, violation budgets, and prediction settings.

From this page, you can:

- Create a new template.
- Edit an existing template.
- Delete a template that is no longer needed.

You can apply a template when you create a new SLA, so you do not have to configure these settings manually every time. For more information, see [Creating an SLA](xref:Managing_SLAs#creating-an-sla).
