# Protocol name

- The protocol name is mandatory and cannot start with "Production".
- Leading and trailing spaces must be trimmed.
- The following characters are forbidden in the protocol name: "`<`", "`>`", "`:`", "`"`", "`/`", "`\`", "`|`", "`?`", "`*`", "`;`", "`°`".
