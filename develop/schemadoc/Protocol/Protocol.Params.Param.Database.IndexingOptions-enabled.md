# enabled attribute

Specifies whether the data of the logger table will be stored in the indexing database instead of in Cassandra.

When set to true, the data of the logger table will be stored in the indexing database instead of in Cassandra.

## Content Type

[EnumTrueFalse](xref:Protocol-EnumTrueFalse)

## Parent

[IndexingOptions](xref:Protocol.Params.Param.Database.IndexingOptions)

## Remarks

Default value: false.
