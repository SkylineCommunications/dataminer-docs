# Option element

Defines an option that can be selected.

## Parent

[Options](xref:Protocol.Settings.Setting.DropDown.Options)

## Attributes

|Name|Type|Required|Description|
|--- |--- |--- |--- |
|[value](xref:Protocol.Settings.Setting.DropDown.Options.Option-value)|[TypeNonEmptyString](xref:Protocol-TypeNonEmptyString)|Yes|Specifies the value stored when this option is selected.|
|[displayName](xref:Protocol.Settings.Setting.DropDown.Options.Option-displayName)|[TypeNonEmptyString](xref:Protocol-TypeNonEmptyString)|Yes|Specifies the name shown to the user for this option.|
