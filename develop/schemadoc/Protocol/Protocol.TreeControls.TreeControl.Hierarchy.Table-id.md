# id attribute

Specifies the parameter ID of the table that is needed in the tree.

## Content Type

unsignedInt

## Parent

[Table](xref:Protocol.TreeControls.TreeControl.Hierarchy.Table)

## Examples

```xml
<Hierarchy>
   <Table id="100"/>
   ...
```
