# id attribute

Specifies the ID of the parameter, command, response, etc. (defined in [Protocol.Triggers.Trigger.On](xref:Protocol.Triggers.Trigger.On)) of which the value will be checked.

## Content Type

unsignedInt

## Parent

[Time](xref:Protocol.Triggers.Trigger.Time)

## Remarks

If this attribute is omitted, the ID specified in the [Protocol.Triggers.Trigger.On](xref:Protocol.Triggers.Trigger.On) element will be taken.
