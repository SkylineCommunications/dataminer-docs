# filter attribute

When set to "true", only printable characters will be displayed.

## Content Type

[EnumTrueFalse](xref:Protocol-EnumTrueFalse)

## Parent

[Type](xref:Protocol.Params.Param.Interprete.Type)

## Remarks

Default: false.
