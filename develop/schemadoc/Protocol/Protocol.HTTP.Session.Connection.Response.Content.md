# Content element

The `pid` attribute of this element specifies the ID of the parameter where you want the contents of the response to be stored.

## Parent

[Response](xref:Protocol.HTTP.Session.Connection.Response)

## Attributes

|Name|Type|Required|Description|
|--- |--- |--- |--- |
|[pid](xref:Protocol.HTTP.Session.Connection.Response.Content-pid)|unsignedInt|Yes|Specifies the ID of the parameter where you want the contents of the response to be stored.|
