# ReadonlyColumns element

Used to hide write controls for certain table columns.

## Type

string

## Parent

[TreeControl](xref:Protocol.TreeControls.TreeControl)

## Examples

```xml
<ReadonlyColumns>103,204</ReadonlyColumns>
```
