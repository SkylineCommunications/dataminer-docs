# SettingRef element

Specifies the setting whose value has to be used as the value of this argument.

## Parent

[Argument](xref:Protocol.Edge.Scripts.Script.Arguments.Argument)

## Attributes

|Name|Type|Required|Description
|--- |--- |--- |--- |
|[id](xref:Protocol.Edge.Scripts.Script.Arguments.Argument.SettingRef-id)|[TypeNonEmptyString](xref:Protocol-TypeNonEmptyString)|Yes|Specifies the ID of the setting (as specified in /Protocol/Settings/Setting@id) whose value has to be used.|
|[field](xref:Protocol.Edge.Scripts.Script.Arguments.Argument.SettingRef-field)|[TypeNonEmptyString](xref:Protocol-TypeNonEmptyString)||Specifies a certain field that has to be selected out of the referenced setting.|
