# protocol attribute

Specifies the ID of the dummy script variable that is referred to.

## Content Type

positiveInteger

## Parent

[Param](xref:DMSScript.Script.Exe.Param)

## Remarks

Used with script actions of type "assigndummy", "get" and "set".
