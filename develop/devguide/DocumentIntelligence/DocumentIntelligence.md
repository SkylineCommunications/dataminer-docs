# Document Intelligence

[Document Intelligence](xref:docintel) is a DataMiner Intelligence capability that provides an API for analyzing documents. The [DataMiner Assistant DxM](xref:Intelligence_Assistant_DxM) powers this capability. You can send one or more documents with custom instructions to extract or analyze content using a large language model (LLM).

The main entry point is the [DocumentIntelligenceHelper](xref:DocIntel_DocumentIntelligenceHelper) class, which exposes the `AnalyzeDocuments` method.
