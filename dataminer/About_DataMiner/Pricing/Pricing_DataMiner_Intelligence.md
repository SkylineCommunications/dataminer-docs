# DataMiner Intelligence pricing

This page describes how [DataMiner Intelligence](xref:DataMiner_Intelligence) usage is metered. DataMiner Intelligence does not require a separate license; it is a usage-based service.

## Usage metering

Usage of DataMiner Intelligence is metered using the following metrics:

| Metric | What it measures |
|--------|------------------|
| Token consumption | The tokens processed by the foundational language models. |
| Tool calls | The actions that agents trigger to interact with DataMiner, such as activating a skill or tool, or reading documentation. |
| Pages processed | The number of pages processed by [Document Intelligence](xref:docintel). |

Like other usage-based services, metering is done at the organization level. See [Billing and metering](xref:Pricing_billing_and_metering).

For page-volume estimates, see [Sizing guide: DataMiner Assistant](xref:Pricing_sizing_guide_services_DataMiner_Assistant).

## Usage-based commercial model

DataMiner Intelligence is usage based. Any applicable usage limits and commercial terms depend on your organization. For more information, contact your Skyline Communications representative.
