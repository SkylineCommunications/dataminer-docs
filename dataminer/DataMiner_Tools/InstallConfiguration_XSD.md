# InstallConfiguration Schema file

For unattended installation of DataMiner using the deprecated v10.2 or v10.0 Installer, a correctly configured *InstallConfiguration.xml* file is required. You can check the validity of this file using this XSD.

You can download this tool from DataMiner Dojo:

- [InstallConfiguration Schema file for the **10.2** Installer](https://community.dataminer.services/download/installconfiguration-xsd-to-be-used-from-dataminer-10-1-0-onwards/).
- [InstallConfiguration Schema file for the **10.0** Installer](https://community.dataminer.services/download/installconfiguration-xsd/).

> [!TIP]
> For more information about unattended DataMiner installation using the deprecated v10.2 or v10.0 Installer, see [Unattended DataMiner installation](xref:Unattended_DM_installation#deprecated-v102-or-v100-installer).
