# DataMiner modules

DataMiner modules are services that extend or support the DataMiner platform.

There are two module types:

- [DataMiner Extension Modules (DxMs)](xref:DataMinerExtensionModules): Optional modules that can be added through the Admin app and through DataMiner upgrade packages.
- [DataMiner Core Modules (DcMs)](xref:DataMinerCoreModules): Core platform modules delivered through the DataMiner installer. DcMs cannot be installed through the Admin app.

> [!TIP]
> This page is intended for administrators and provides information on modules that run in the background of a DataMiner System. If you are looking for information about the "modules" listed in the DataMiner Cube *Apps* pane, refer to [Functions](xref:Overview_Functions).
