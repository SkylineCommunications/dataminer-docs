# Installing an Edge Node

An Edge Node runs Python-based integrations close to the operational data they collect. Before you can use an Edge Node, you must install it and register it with a DataMiner System.

An Edge Node can connect to the DataMiner System in one of the following ways:

- Through dataminer.services.

- Directly over the local network.

We recommend connecting through dataminer.services. Only use a direct connection if your environment specifically requires it.

## Prerequisites

Make sure the following requirements are met:

- DataMiner version 10.5.0 [CU19]/10.6.0 [CU7]/10.6.10 or higher.

- The latest version of the [SiteManager DxM](xref:DataMinerExtensionModules#sitemanager).

- The latest version of the [DataAPI DxM](xref:DataMinerExtensionModules#dataapi).

- A registration key for the selected connection mode, as detailed below.

  > [!IMPORTANT]
  > Treat DataMiner System keys and pre-shared keys as sensitive information. Do not include them in documentation, support packages, or other content that may be shared.

### Connection through dataminer.services

To register an Edge Node that connects through dataminer.services, you need a DataMiner System key:

1. In the [Admin app](https://admin.dataminer.services/), under *DataMiner Systems* in the sidebar on the left, select the DataMiner System you want to connect the Edge Node to and go to the *Keys* page.

1. Copy an existing primary key or generate a new key.

You will need this key when you install or configure the Edge Node.

### Direct connection

To register an Edge Node that connects directly to the DataMiner System, you need a pre-shared key generated by the SiteManager DxM:

1. Open DataMiner Cube on the DataMiner Agent that should receive data from the Edge Node.

1. Go to *Apps* > *System Center* > *Logging* > *Site Manager (DxM)*.

1. Search the log file for the following message:

   ```txt
   EdgeNode registration PSK: <pre-shared key>. This PSK can be used to register your edge nodes.
   ```

1. Copy the pre-shared key.

You will need this key and the fully qualified domain name of the DataMiner Agent when you install or configure the Edge Node.
