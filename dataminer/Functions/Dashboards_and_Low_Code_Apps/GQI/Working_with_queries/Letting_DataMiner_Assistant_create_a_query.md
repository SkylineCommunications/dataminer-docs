# Letting DataMiner Assistant create a GQI query

Using the DataMiner Assistant [natural language to GQI feature](xref:Intelligence_NL2GQI) feature, you can automatically create a GQI query based on a request in natural language.

To do so, when you click the "+" button to add a query, type your request in the textbox and click **Generate query**. DataMiner Assistant will then create the desired GQI query and generate a relevant query name.

![Natural language to GQI query generation in a DataMiner dashboard](~/dataminer/images/NL2GQI.png)<br>*Natural language to GQI feature in DataMiner Web 10.6.1.*

Keep in mind that **DataMiner Assistant can make mistakes**. We recommend manually checking the resulting queries and correcting or extending them to your liking when necessary. Note that typing a new request and clicking the button a second time will override the query, causing any manual changes to be lost.

> [!TIP]
> For information on the **requirements** for this feature, refer to [Natural language to GQI](xref:Intelligence_NL2GQI#requirements).
