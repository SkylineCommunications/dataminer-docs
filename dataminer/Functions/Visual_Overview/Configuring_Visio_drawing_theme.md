# Configuring the Visio drawing theme

From DataMiner 10.5.0 [CU19]/10.6.0 [CU7]/10.6.10 onwards<!--RN 45961-->, you can select the theme used by Visio drawings in Visual Overview.

To configure the theme for Visio drawings:

1. Go to *System Center* > *System settings* > *Visio drawing*.

1. Select the theme you want to use:

   - **Follow Cube theme** (default): Visio drawings use the same theme as DataMiner Cube.

   - **Light**: Visio drawings always use the light theme, regardless of the DataMiner Cube theme.

   > [!NOTE]
   > A dedicated dark theme for Visio drawings is not available. To display Visio drawings with a dark theme, DataMiner Cube must use the dark theme and the *Follow Cube theme* option must be selected. While a dark Cube theme can be combined with a light Visio drawing theme, the reverse is not possible.

1. Click *Apply theme*.

1. Reopen any open Visio drawings.

   The selected theme is applied to the drawings.
