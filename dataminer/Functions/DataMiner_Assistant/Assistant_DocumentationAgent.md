# DataMiner Docs agent

DataMiner Docs is a native agent in the [Assistant app](xref:DataMinerAssistant) that provides answers based on DataMiner documentation. It helps you quickly find relevant information without manually searching through the documentation.

The DataMiner Docs agent searches the public DataMiner documentation to find relevant information. When you ask a question, the agent retrieves the most relevant documentation pages and formulates an answer based on the official DataMiner documentation.

You can for example use the DataMiner Docs agent for the following purposes:

- To get quick answers about DataMiner features and configuration.
- To find relevant documentation for troubleshooting.
- To understand DataMiner concepts without navigating through multiple pages.
