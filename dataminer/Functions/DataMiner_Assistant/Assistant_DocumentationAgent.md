# DataMiner Docs agent

DataMiner Docs is a native agent in the [Assistant app](xref:DataMinerAssistant) that provides answers based on DataMiner documentation. It helps you quickly find relevant information without manually searching through the documentation.

The DataMiner Docs agent searches the public DataMiner documentation at <https://docs.dataminer.services> to find relevant information. When you ask a question, the agent retrieves the most relevant documentation pages and formulates an answer based on the official DataMiner docs.

You can for example use the DataMiner Docs agent for the following purposes:

- Getting quick answers about DataMiner features and configuration.
- Finding relevant documentation for troubleshooting.
- Understanding DataMiner concepts without navigating through multiple pages.
