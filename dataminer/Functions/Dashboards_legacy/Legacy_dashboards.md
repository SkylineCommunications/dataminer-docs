# DMS Dashboards (legacy)

DMS Dashboards is a legacy module that allows you to design and view customized dashboards, both within DataMiner Cube and in a standalone app. In recent DataMiner versions, this module has been replaced by the [Dashboards app](xref:newR_D).

> [!IMPORTANT]
> From DataMiner 10.7.0/10.7.1 onwards, this module is **End of Life** and no longer available.<!-- RN 47135+47136 --> See [DataMiner functionality evolution and retirement](xref:Software_support_life_cycles#dataminer-functionality-evolution-and-retirement).

> [!NOTE]
> From DataMiner 10.4.0/10.4.1 onwards, this module is disabled by default.<!-- RN 37786 --> In versions prior to its End of Life, you can enable it with the [*LegacyReportsAndDashboards* soft-launch option](xref:Overview_of_Soft_Launch_Options#legacyreportsanddashboards).
>
> From DataMiner 10.2.0/10.1.12 onwards, you can optionally disable this module with the same soft-launch option.
