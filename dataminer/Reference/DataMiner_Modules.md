# DataMiner modules

DataMiner modules are services that extend or support the DataMiner platform.

There are two module types:

- **DataMiner Extension Modules (DxMs)**: Optional modules that can be added through the Admin app and through DataMiner upgrade packages.
- **DataMiner Core Modules (DcMs)**: Core platform modules delivered through the DataMiner installer. DcMs cannot be installed through the Admin app.

For detailed information, refer to the following topics:

- [DataMiner Extension Modules (DxMs)](xref:DataMinerExtensionModules)
- [DataMiner Core Modules (DcMs)](xref:DataMinerCoreModules)
